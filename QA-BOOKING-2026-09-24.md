# Онлайн-запись «СТО Центр» — что сделано и как проверено (24.09.2026)

Запрос: «должна быть менюшка записи именно, с выбором услуг, машины и т.д., тут вроде цены есть
в 2ГИСе, доработай до продакшена».

Сделано: полноценная запись с выбором услуги **из прайса 2ГИС вместе с ценой**, данными
автомобиля, датой и временем внутри реального графика, контактами, экраном подтверждения,
панелью заявок для владельца и хранилищем, которое настраивается под хостинг.

---

## 1. Сценарий записи (5 шагов)

| Шаг | Что делает пользователь | Что подставлено из реальных данных |
|---|---|---|
| 1. Услуга | ищет по прайсу или выбирает из 8 частых позиций | 93 позиции прайса 2ГИС с ценами, две группы («Услуги» 58 и «Ремонт 4-цилиндровых двигателей» 35); вариант «Другое — опишу в комментарии» |
| 2. Автомобиль | марка и модель (подсказка — 19 марок из 2ГИС), год, VIN (не обязателен), «что беспокоит» | марки из блока «Авторемонт» карточки 2ГИС |
| 3. Дата | календарь и чипы «Сегодня / Завтра / Через 3 дня» | график 2ГИС: Пн–Пт 09:00–19:00, Сб 09:00–18:00, Вс — закрыто; прошедшие дни недоступны |
| 4. Время | слоты по часам | будни 09:00–18:00, суббота 09:00–17:00 (последний заезд за час до закрытия), сегодняшние прошедшие слоты скрыты с запасом 1 час |
| 5. Контакты | имя, телефон с маской +7, канал связи (телефон / WhatsApp / Telegram), ник для Telegram | телефоны и WhatsApp сервиса из 2ГИС |
| Экран подтверждения | номер заявки, сводка (услуга, цена по прайсу, авто, дата/время, связь), «что дальше», кнопки «Позвонить» и «Написать в WhatsApp» с номером заявки | адрес и телефоны сервиса из 2ГИС |

Точки входа: шапка, hero («Записаться на сервис»), каждая карточка услуг (услуга подставляется
сразу вместе с ценой), контакты, фиксированная панель на телефоне («Записаться / Позвонить»).

## 2. Инженерные решения

- **Валидация одна и та же на клиенте и сервере** (`lib/validation.ts`): услуга только из прайса,
  имя 2–80, телефон 11 цифр, год 1950–текущий+1, VIN 11–17 без I/O/Q (кириллица, похожая на
  латиницу, приводится к латинице: `wdв211` → `WDB211`), дата — рабочий день не дальше 60 дней,
  время — только из доступных слотов, Telegram-ник — при выбранном канале Telegram.
- **Защита от двойной заявки**: синхронный ref-замок в отправке (проверено: два клика с
  интервалом 0.2 мс → один POST, одна заявка).
- **Ловушка для ботов**: скрытое поле `hp_nickname` (+ подсказки для менеджеров паролей).
  Если оно заполнено, API отвечает `200 {silent:true}` и заявку не создаёт, а форма показывает
  понятный текст и кнопку WhatsApp — раньше в этом случае форма «зависала» без объяснения.
- **Ошибки без техноты**: при недоступном API посетитель видит «Попробуйте ещё раз или
  позвоните: +7 (7162) 29-35-35» и кнопку отправки заявки в WhatsApp с уже готовым текстом
  (услуга, авто, дата, имя, телефон) — заявка не теряется.
- **Хранилище** (`lib/bookings.ts`): KV (Upstash / Vercel KV) → файл `data/bookings.json` → память
  (демо-режим с честным предупреждением в панели). Запись сериализуется очередью, битый файл
  не роняет сайт (откладывается в сторону). Дополнительно — уведомление в Telegram
  (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).
- **Панель заявок `/admin`** (`lib/auth.ts`: httpOnly-cookie с HMAC-подписью, 12 часов):
  фильтры по статусам, смена статуса, «Позвонить», «Подтвердить в WhatsApp» одним нажатием,
  удаление, очистка проверочных записей, предупреждение о пароле по умолчанию и о временном
  хранилище. Страница закрыта `robots` и `noindex`.
- **Доступность и мобильный UX**: модалка на весь экран, блокировка прокрутки страницы
  (и `html`, и `body`), ловушка фокуса, Escape, возврат фокуса, `aria-modal`, `role="alert"`
  у ошибок, `aria-invalid` у полей, `aria-pressed` у вариантов, все цели ≥44×44,
  поля 48 px и шрифт 16 px (без авто-зума в iOS), `inputmode="tel"`.

## 3. Проверено

**API (скрипт `scripts/qa-bookings-api.mjs`) — 15/15:**
валидная заявка создаётся (201) · цена подставляется из прайса (2 500 ₸) · некорректные поля
отклоняются (400 + список полей) · воскресенье недоступно · время вне графика отклоняется ·
для Telegram требуется ник · короткий VIN отклоняется · ловушка ботов отвечает 200 и не создаёт
заявку · список без входа 401 · неверный пароль 401 · вход выдаёт cookie · список доступен
после входа · заявка видна в панели · статус меняется · заявка удаляется.

**Браузер (мобильный, 390×844 и 320×568):**
открытие из всех 5 точек, в том числе с подстановкой услуги и цены · модалка на весь экран,
страница под ней не прокручивается · закрытие (крестик, Escape, фон) · поиск по прайсу
(«рейка» → 2 позиции, «колодки» → 2, «диагностика» → 1) · раскрытие всех 93 позиций двумя
группами · «цена по запросу» у позиции без цены · VIN и маска телефона · календарь без
переполнения (ячейки 33×44 на 320, 44×44 на 390) · слоты 10 в будни и 9 в субботу ·
сводка и экран подтверждения · двойной тап = одна заявка · 0 ошибок консоли ·
0 переполнений на 320–1920 · 0 интерактивных элементов меньше 44×44.

**Сборка:** `npx tsc --noEmit`, `npm run lint` — чисто, `npm run build` — успешно
(`/` 20 kB / 127 kB First Load JS, `/admin` 9.6 kB, API-роуты динамические).

## 4. Что нужно сделать перед публикацией

1. `ADMIN_PASSWORD` — обязательно свой пароль (иначе панель с заявками открыта всем);
   при желании `ADMIN_SECRET`.
2. Хранилище: на VPS/Docker ничего не нужно; на Vercel — KV (`KV_REST_API_URL` /
   `KV_REST_API_TOKEN`). Рекомендуется Telegram-уведомление о новых заявках.
3. Проверить у владельца **актуальность цен** — прайс в 2ГИС обновлён 25.06.2020,
   в форме и на сайте стоит пометка, что стоимость подтверждает мастер после осмотра.
4. Согласовать сетку слотов: часы взяты из графика 2ГИС, а шаг (1 час) и правило
   «последний заезд за час до закрытия» — решение сайта; при необходимости легко поменять
   в `lib/slots.ts`.
5. Проверить политику конфиденциальности: форма собирает имя, телефон и данные авто —
   текст в футере стоит дополнить под фактическую обработку контактов.

Все тестовые заявки из проверок удалены из `data/bookings.json`.
