# СТО Центр — сайт автосервиса (Кокшетау)

Одностраничный сайт автосервиса **СТО Центр** (улица Шанырак, 6а/с, Кокшетау)
с онлайн-записью, каталогом прайса и панелью заявок.
Все данные — из открытой карточки 2ГИС: <https://2gis.kz/kokshetau/firm/70000001034161553>.
Ничего не придумано: если факта нет в карточке, его нет и на сайте.

Стек: **Next.js 15 (App Router)**, TypeScript, Tailwind CSS 4, `lucide-react`.
Внешних UI-, анимационных и картографических библиотек нет.

### Логотип

Знак — **шестигранник гайки с вырезанным зевом ключа**: одна форма читается
трижды — как гайка (крепёж, техника), как открытый зев гаечного ключа и как
кириллическая «С» — первая буква названия. Никаких клише вроде машинки или
гаечного ключа «в лоб», никакого сходства с чужими товарными знаками.

Геометрия задана числами, а не нарисована на глаз, поэтому знак остаётся
чистым в любом размере — от favicon 16 px до печати:

| Элемент | Формула |
|---|---|
| Шестигранник | центр (32, 32), описанный радиус 31, вершины слева и справа |
| Зев ключа | кольцо R = 20.5 / r = 10.5 вокруг центра, раскрытие 60° вправо |

Цвета: оранжевый `#FF6A1A` (поле знака) и белый (зев) — те же токены
`brand` и `white`, что и во всём интерфейсе. Для одноцветной печати,
гравировки и тиснения есть монохромная версия: зев вырезан через
`fill-rule="evenodd"`, цвет наследуется от `currentColor`.

Файлы:

| Файл | Назначение |
|---|---|
| `components/Logo.tsx` | `<LogoMark variant="brand"｜"mono">` и `<LogoLockup>` для вёрстки |
| `app/icon.svg` | favicon: знак на тёмной плитке со скруглением |
| `public/brand/logo-mark.svg` | знак для партнёров и типографии |
| `public/brand/logo-mark-mono.svg` | одноцветный знак |
| `public/brand/logo-lockup.svg` | знак + название + город |
| `public/brand/brand-board.svg` | брендборд: размеры от 16 до 96 px, варианты, палитра |

В вёрстке название рядом со знаком — **живой текст Manrope ExtraBold**, а не
картинка: он масштабируется вместе с макетом, читается скринридером и
индексируется. В SVG-файлах логотипа шрифт подставляет система (SVG не несёт
встроенных шрифтов) — если отдаёте файл в печать, текст там лучше заменить
на кривые.

## Онлайн-запись

Открывается из шапки, hero, карточек услуг, каталога цен, блока `#zapis`,
контактов и нижней панели на телефоне. Пять шагов — один вопрос на экран:

1. **Что нужно сделать** — услуга из прайса (93 позиции): поиск по названию,
   группы, «показать весь прайс», вариант «Другое — опишу в комментарии», цена подставляется.
2. **Ваш автомобиль** — марка/модель, год, VIN, «что беспокоит». Все поля
   необязательные, шаг можно пропустить.
3. **Когда удобно** — «Сегодня / Завтра / Через 3 дня» или календарь; свободные
   часы внутри реального графика: Пн–Пт 09:00–19:00, Сб 09:00–18:00, Вс — закрыто,
   последний заезд за час до закрытия, запись на 60 дней вперёд.
4. **Контактные данные** — имя, телефон с маской +7, канал связи (телефон /
   WhatsApp / Telegram), при Telegram — ник.
5. **Подтверждение** — сводка заявки, отправка, экран «Заявка принята» с номером.

Валидация одна и та же на клиенте и на сервере (`lib/validation.ts`),
данные об автомобиле необязательны — пустые поля не попадают ни в панель,
ни в Telegram. Есть ловушка для ботов, защита от двойной отправки и резервная
кнопка «Отправить заявку в WhatsApp», если API недоступен.

## Перед публикацией

1. Задать домен, чтобы OG-картинки, `robots.txt` и `sitemap.xml` были абсолютными:
   скопировать `.env.example` в `.env.local` и указать `NEXT_PUBLIC_SITE_URL=https://ваш-домен.kz`
2. **Обязательно** задать `ADMIN_PASSWORD`. Без него в продакшене вход в панель заявок
   (`/admin`) полностью закрыт. Сессия подписывается `ADMIN_SECRET`
   (если не задан — выводится из пароля).
3. Настроить, куда складывать заявки: на VPS/Docker ничего не нужно (файл `data/bookings.json`),
   на Vercel/Netlify — подключить Upstash Redis / Vercel KV. Рекомендуется также указать
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, чтобы заявка приходила мастеру сообщением.
4. Уточнить у владельца актуальность цен (прайс в 2ГИС обновлён 25.06.2020) —
   на сайте об этом есть пометка рядом с ценами.
5. При желании — заменить карту OpenStreetMap на виджет 2ГИС (нужен API-ключ 2ГИС).

## SEO и доступность

- `title`, `description`, Open Graph, Twitter Card, `canonical`, favicon (`app/icon.svg`),
  `sitemap.xml`, `robots.txt` (закрывает `/admin` и `/api`)
- JSON-LD `AutoRepair`: адрес, координаты, телефоны, часы работы, рейтинг,
  `makesOffer` из реальных позиций прайса с ценами в KZT, `sameAs` → 2ГИС
- один `h1`, далее `h2`/`h3` по блокам, семантические `section`/`ul`/`dl`/`ol`
- весь интерактив доступен с клавиатуры: Escape закрывает модальные окна,
  фокус возвращается на кнопку-источник, пропуск фокуса ограничен окном,
  свёрнутые блоки помечены `inert`
- контраст: белый на `#08090c` — 19:1, `mist` на `steel` — 7,7:1,
  оранжевый на тёмном — 6,3:1, `brand-ink` на светлом — 4,9:1
- `prefers-reduced-motion` отключает все анимации, содержимое видно и без JS
  (блоки скрываются только после гидратации и только ниже первого экрана)

## Проверено

- 320 / 360 / 375 / 390 / 430 / 768 / 1024 / 1280 / 1440 px — горизонтального
  переполнения нет (`scrollWidth − clientWidth = 0`), контент не обрезан;
  на 320 px длинная кнопка «Записаться на обслуживание» переносится на две строки
- консоль: 0 ошибок, 0 предупреждений, 0 ошибок гидратации, все запросы 200
- все ссылки (`tel:`, `wa.me`, 2ГИС, маршрут) непустые и корректные
- запись: 5 шагов, пропуск шага «Автомобиль», отправка одним запросом
  (`POST /api/bookings` → 201), экран подтверждения с номером, двойной тап
  не создаёт вторую заявку
- каталог цен: поиск «рейка» → 2 позиции, группы (58 / 35), закрытие по Escape и по кнопке
- галерея: 7 фото, лайтбокс со стрелками, Escape, клик по фону, свайп на телефоне
- нижняя панель на телефоне: три кнопки 52 px, не перекрывает подвал (запас 19 px)
- `/admin`: гейт пароля, список заявок, смена статуса сохраняется после обновления

## Чего на сайте нет и почему

- **CRM, аккаунтов клиентов, личного кабинета** — для одного сервиса это лишнее:
  заявки приходят в `/admin` и (при настройке) в Telegram.
- **Онлайн-оплаты и предоплаты** — в 2ГИС указаны только наличные и перевод с карты.
- **Соцсетей и отдельного сайта** — в карточке 2ГИС у организации они не указаны.
- **Отзывов сверх двух** — в 2ГИС 5 отзывов, для блока выбраны два коротких
  (остальные длинные, часть с претензиями к ценам); ссылка ведёт на все отзывы в 2ГИС.
- **Обещаний опыта, гарантий и оригинальных запчастей** — таких сведений в 2ГИС нет,
  поэтому блок «Почему мы» собран только из проверяемых фактов.
- **Фотостока** — в галерее и первом экране только реальные фотографии из 2ГИС.
