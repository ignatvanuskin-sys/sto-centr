# СТО Центр — сайт-визитка (Кокшетау)

Одностраничный сайт автосервиса **СТО Центр** (улица Шанырак, 6а/с, Кокшетау).
Все данные — из открытой карточки 2ГИС: <https://2gis.kz/kokshetau/firm/70000001034161553>.
Ничего не придумано: если факта нет в карточке, его нет и на сайте.

## Стек

- Next.js 15 (App Router), TypeScript
- Tailwind CSS 4
- lucide-react (иконки)
- Внешних UI-библиотек, анимационных и картографических пакетов нет

Сборка: `/` — 20 kB страницы (127 kB First Load JS), `/admin` — 9,6 kB (117 kB),
`/api/bookings` — динамический. Главная статическая, JS отвечает за раскрытие прайса,
лайтбокс, статус «Открыто/Закрыто» и форму онлайн-записи.

## Перед публикацией

1. Задать домен, чтобы OG-картинки, `robots.txt` и `sitemap.xml` были абсолютными:
   скопировать `.env.example` в `.env.local` и указать `NEXT_PUBLIC_SITE_URL=https://ваш-домен.kz`
2. **Обязательно** задать `ADMIN_PASSWORD`. Без него в продакшене вход в панель заявок
   (`/admin`) полностью закрыт: сайт отказывает в логине и объясняет, что нужно добавить
   переменную. Так заявки клиентов не утекут, даже если адрес панели кто-то найдёт.
   Локально пароль лежит в `.env.local` (в git не попадает). Сессия подписывается
   `ADMIN_SECRET` (если не задан — выводится из пароля).
3. Настроить, куда складывать заявки: на VPS/Docker ничего не нужно (файл `data/bookings.json`),
   на Vercel/Netlify — подключить Upstash Redis / Vercel KV. Рекомендуется также указать
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, чтобы заявка приходила мастеру сообщением.
4. Уточнить у владельца актуальность цен (прайс в 2ГИС обновлён 25.06.2020).
5. При желании — заменить карту OpenStreetMap на виджет 2ГИС (нужен API-ключ 2ГИС).

## Онлайн-запись

Открывается из шапки, hero, карточек услуг (с подстановкой услуги), контактов и нижней
панели на телефоне. Пять шагов: **услуга → автомобиль → дата → время → контакты**,
затем экран подтверждения с номером заявки.

- **Услуга с ценой** — выбор из 93 позиций прайса 2ГИС (поиск по названию + раскрытие обеих
  групп), цена подставляется в заявку. Есть вариант «Другое — опишу в комментарии»
  и подпись, что стоимость мастер подтверждает после осмотра.
- **Автомобиль** — марка и модель (подсказки — 19 марок из 2ГИС), год, VIN (не обязательно,
  проверяются 11–17 символов без I/O/Q) и «что беспокоит».
- **Дата и время** — только внутри реального графика: Пн–Пт 09:00–19:00, Сб 09:00–18:00,
  Вс — закрыто. Слоты почасовые, последний заезд за час до закрытия; сегодняшние прошедшие
  слоты скрыты (запас 1 час). Запись открыта на 60 дней вперёд.
- **Контакты** — имя, телефон с маской +7, канал связи (телефон / WhatsApp / Telegram),
  для Telegram — ник. Перед отправкой показывается сводка заявки.
- **Надёжность** — валидация на клиенте и на сервере (одни и те же правила), защита от
  двойной отправки, ловушка для ботов, понятный текст ошибки без технических деталей,
  резервная кнопка «Отправить заявку в WhatsApp», если API недоступен.
- **Панель заявок** `/admin` — список с фильтрами по статусам, смена статуса, звонок,
  «подтвердить в WhatsApp» одним нажатием, удаление. Панель закрыта `robots` и требует пароля.

Слоты и «последний заезд за час до закрытия» — это решение сайта: в 2ГИС заданы только
часы открытия и закрытия, поэтому форма записи использует почасовую сетку внутри них.

## SEO

- `title`: «СТО Центр — автосервис в Кокшетау: ремонт стартеров, генераторов и ходовой»
- `description`, Open Graph, Twitter Card (картинка — фото фасада)
- один `h1`, далее `h2`/`h3` по блокам, семантические `section`/`ul`/`dl`
- JSON-LD `AutoRepair`: адрес, координаты, телефоны, часы работы, рейтинг, `sameAs` → 2ГИС

## Проверено

- 320 / 360 / 375 / 390 / 430 / 768 / 1280 / 1440 px — горизонтального переполнения нет
- консоль: 0 ошибок и предупреждений (hydration-ошибок нет), все запросы 200
- все ссылки: `tel:`, `wa.me`, 2ГИС, маршрут — проверены; пустых `href="#"` нет
- прайс раскрывается (58 + 35 позиций), лайтбокс: стрелки, Escape, клик по фото
- нижняя мобильная панель не перекрывает футер
- запись: 5 шагов, отправка одним запросом, двойной тап не создаёт вторую заявку,
  при недоступном API показывается понятный текст и кнопка WhatsApp

## Чего на сайте нет и почему

- **CRM, аккаунтов клиентов, личного кабинета** — для одного сервиса это лишнее:
  заявки приходят в `/admin` и (при настройке) в Telegram.
- **Онлайн-оплаты и предоплаты** — в 2ГИС указаны только наличные и перевод с карты.
- **Соцсетей и сайта** — в карточке 2ГИС у организации они не указаны.
- **Отзывов сверх двух** — в 2ГИС 5 отзывов, для блока выбраны два коротких (остальные
  длинные, часть с претензиями к ценам); ссылка на все отзывы ведёт в 2ГИС.
- **Раздела «Преимущества/гарантии»** — в 2ГИС таких сведений нет, выдумывать нельзя.
